# research

官方資料來源的實測紀錄，供維護時對照；不參與測試、建置或發布。

- `taifex-mis/`：期交所 MIS 請求參數與回應封包，`manifest.json` 記錄網址、時間與 sha256。
- `completion-fixtures.json`：目錄與規格回應的來源紀錄，對應 `tests/fixtures/`。
- `source-probes.json`：各資料來源的探測結果。

Recorded responses from official market-data sources, kept for reference. Not used by
tests, builds or releases.
